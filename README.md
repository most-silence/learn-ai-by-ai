# Learn AI By AI

以动手做项目为主，边学 AI 边用 AI 记录进度、评估掌握度、迭代学习路线。

## 目录结构

```
Learn AI By AI/
├── ROADMAP.md      # 学习路线图（阶段/模块/资源/迭代机制）
├── PROGRESS.md     # 进度追踪（掌握度 + 项目 + 周回顾 + 卡点）
├── notes/          # 学习笔记（按阶段分文件，如 notes/phase0.md）
├── projects/       # 实战项目代码（每阶段一个子目录）
├── data/           # 练习数据集（如 titanic.csv）
├── EXERCISES_INDEX.md # 练习索引表（阶段/课/主题/文件名/状态，一眼看清在哪）
├── ex_phaseN_lessonM_主题.py  # 课后练习，命名与教材对应（如 ex_phase2_lesson2_metrics_overfit.py 配 notes/phase2_lesson2.md；文件顶部有标准头：阶段/课/主题/日期/状态）
```

## 如何使用

1. **每天学完**：在 `PROGRESS.md` 对应阶段表格里加一行（日期/内容/掌握度/证据），并写一个可运行的产出。
2. **每课顺序（2026-10-02 定稿）**：开场复习（不翻笔记）→ **先裸做练习**（卡住可看脚手架/教材对应节）→ 读教材校准 → 回头重答复习题。练习先行记得更牢（生成效应，10-02 由学员实践发现）。
3. **每课练习（代码规则）**：练习文件只含任务说明 + 预测区 + 空代码区。**先自己写预测和代码**并运行，提交后再由 AI 补「标准答案区」供对比；不标准/错误写法记入文件「对比记录」和 `PROGRESS.md` 卡点表。练习文件里永远不预先给答案代码；卡住超 5 分钟由 AI 给填空式脚手架（骨架在、关键处留空）。
4. **预测分两类**：可推导预测（从工具语义必然推出的结果，**必做**，检验理解）；校准预测（未知数字凭直觉猜，**选做**，建立数据直觉，没把握可标"弃权"）。
5. **卡点退休规则**：同一卡点需在**两个不同日子**各答对一次才算固化；只通过一次的继续保留复查。
6. **每日配额**：复习 5 分钟 + 1 课新内容为标准量；想加量做练习文件里的"加餐"题或自由探索，不连开第二课（防 10-01 式过载）。
2. **做完项目**：登记到「项目记录」表；代码放在 `projects/` 对应子目录。
3. **每周日 5 分钟**：填「周回顾」，复盘并定下周计划。
4. **卡住或调整方向**：记进「卡点与调整」，下次会话据此迭代 `ROADMAP.md`。

## 协作方式

在这个目录打开 Claude（`claude` 命令），直接说「更新进度」「回顾这周」「下一步学什么」，
我会读取 `ROADMAP.md` / `PROGRESS.md` 帮你记录、评估并迭代计划。
