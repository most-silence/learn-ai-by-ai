随机森林速查卡

参数、默认值、诊断信号、常见误解

配套：第 4 课补充 2026-10-29

一行定义

森林 = 很多棵"看不同数据 + 看不同特征"的深树，投票定结论

两个随机（森林的全部秘密）

随机做法效果
数据随机
bootstrap		有放回抽 N 个样本每棵看到约 63.2% 的不同样本；剩下 36.8% 是 OOB
特征随机
max_features		每次分叉只从随机子集挑最优分类默认 sqrt（6 特征 → 每次只看 2 个）
⚠ 最常见的混淆

"两个随机"不是 random_state 的两个位置。前者是机制，后者是控制机制怎么抽的开关。

关键参数

n_estimators
树的数量，默认 100。越多越稳，但有边际递减：n=10 → 0.8024，n=50 → 0.8038，n=500 → 0.8010。不会因为树多而过拟合。
max_depth
默认 None = 每棵树长到底。动它是在调 strength，不是 correlation（限深后 ρ 反而升高）。
max_features
默认 sqrt（分类）/ 1.0（回归）。调小 → 树更多样但更弱；调大 → 更准但更像。这是 Breiman 说森林唯一敏感的旋钮。
oob_score
默认 False。设 True 可白拿一个验证分数（用每棵树没抽到的 36.8%）。实测 OOB 0.8090 vs test 0.7989，偏差小。
bootstrap
默认 True。关掉就没有"数据随机"，只剩特征随机，不再是随机森林。
random_state
控制上面两处随机。20 个种子下极差仅 1.68pp（单棵满树 2.23pp）—— 森林比单树稳。

诊断表：看到什么数字 → 想到什么

现象含义怎么办
train 0.98 / test 0.75满树重度过拟合限深，或换森林
森林 train 和单树 train 一样正常。森林不减少背题别指望它降 train
森林单棵 test 平均 低于 单树正常。每棵只用 63.2% 数据看投票结果，不看单棵
投票 ≈ 单棵平均树之间太像，投票无效调小 max_features
森林输给限深单树数据小 + 方差本来就低直接用单树，别硬上森林

口诀：树越深 bagging 越赚，树越浅 bagging 越亏。因为 bagging 只削方差，浅树本来就没有方差。

常见误解清单

  • ❌ 森林一定比单树强。小数据上常输。Titanic：0.8017 vs 0.8277。
  • ❌ 森林靠减少背题取胜。train 分数和满树完全相同。
  • ❌ 限深让树更不像。ρ 从 0.596 升到 0.688。
  • ❌ 树越多方差越小，能降到零。下界是 ρσ²，实测 0.1441 就到底了（ρ=0.596 太高）。
  • ❌ feature_importances_ 是"真实重要性"。它基于训练集、偏向高基数特征，且高度相关的特征会互相分票（Fare 和 Pclass）。

最小可用代码

from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import RepeatedStratifiedKFold, cross_val_score

model = RandomForestClassifier(
    n_estimators=100,
    max_features='sqrt',   # 默认
    max_depth=None,        # 小数据上建议改 5~8
    oob_score=True,
    random_state=42,
)

# 比较模型一律用重复 CV（单次 CV 噪声 ±2pp）
cv = RepeatedStratifiedKFold(n_splits=5, n_repeats=10, random_state=0)
scores = cross_val_score(model, X_train, y_train, cv=cv)
print(f"CV mean={scores.mean():.4f} std={scores.std():.4f}")

model.fit(X_train, y_train)
print(f"OOB={model.oob_score_:.4f} test={model.score(X_test, y_test):.4f}")
print(dict(zip(X.columns, model.feature_importances_)))
