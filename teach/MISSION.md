# Mission: 机器学习 → 深度学习 → 大模型 → AI Agent

## Why

要把"AI Agent"从概念变成能自己动手做出来、能跑在自己电脑上的东西。不是做调包侠，而是能看懂一个模型为什么这样表现、能在它表现不对的时候知道该往哪儿查。最终产出是一个真正能用的个人助理 Agent，而不是跑通别人教程的复现。

## Success looks like

- 给一份从没见过的新数据，能独立走完"清洗 → 特征 → 建模 → 评估 → 调参 → 报告"全流程
- 看到一个新模型的分数，能说出它为什么高/为什么低，并指出瓶颈在哪（数据量、偏差、方差、相关性、泄漏）
- 能手算一个算法的核心一步（决策树的分裂增益、梯度的下降方向、注意力权重的含义）
- 能自己写一个 Agent：接工具、带记忆、能处理失败重试，跑在本地
- 能在 Kaggle/社区里提问，且问得出别人愿意回答的问题

## Constraints

- **节奏：工作日 1 小时 × 5 + 周末 3 小时 × 2 = 11 小时/周**（2026-10-29 起强制按日排期，见 `SCHEDULE.md`）
- 硬件：Windows + 本地 CPU（无独显算力），大模型阶段需依赖 API 或量化小模型
- 偏好中文讲解；要**真实运行的数据**支撑结论，不接受"一般来说"式的空话
- 练习前必须先写预测（code-last）：先押注再验证，对错都要记
- 答错要当场精讲、记入卡点表；不连开两课（防止工作记忆过载）
- 卡点退休规则：同一卡点需在**两个不同日子**各答对一次才固化

## Out of scope

- 传统 CV/NLP 的论文级细节（知道有这回事即可，不当主线）
- 训练自己的大模型基座（成本不允许）
- 学术写作 / 刷榜（除阶段 7 可选）
- 前端/工程化（Agent 落地时够用就行，不专门学）
