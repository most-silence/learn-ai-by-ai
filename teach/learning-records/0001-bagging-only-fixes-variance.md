# Bagging 只治方差，不治偏差

用户问"森林默认满树为什么效果差、限深后才追上 d3 树"。查证后得到两个反直觉结论：(1) 限深后树间相关性**升高**（ρ 0.596→0.688），森林变好靠的是 strength 而非 correlation；(2) 单棵 d=3 树的方差**恰好为零**（20 个种子极差 0.0000），bagging 无方差可削，却仍要付"每棵树只看 63.2% 数据"的代价，所以净亏（CV 0.8063 vs 单树 0.8277）。

这改变后续教学的重点：以后讲任何集成方法，必须先问"基础模型的方差有多大"，否则"集成一定更强"会变成错误直觉。也说明"重采样代价"（63.2%）在小数据上不可忽略。

## Implications

- 阶段 2 剩下的课（线性回归 / 逻辑回归 / GridSearchCV）里，凡涉及模型比较，一律用 `RepeatedStratifiedKFold`，单次 CV 的噪声（±2pp）比待比较的差距还大。
- 阶段 3 讲 Dropout / 数据增强时，可以复用同一个框架："这项技术削的是偏差还是方差？"
- 下一步可讲 Boosting：它是**削偏差**的，正好与本课形成对照，且能解释"为什么 GBDT 默认浅树反而对"。
