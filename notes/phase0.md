- Jupyter Notebook 7.0.8 / Lab 4.0.11 可用

- git 2.47.0 可用

## AI 知识地图（从大到小）

```
人工智能(AI) —— 让机器像人一样思考
 └─ 机器学习(ML) —— 从数据中找规律，不用显式编程
     ├─ 深度学习(DL) —— 用多层神经网络自动学特征
     │   ├─ CNN → 图像
     │   └─ RNN/Transformer → 文字/序列
     └─ 经典ML —— sklearn：回归/分类/聚类/决策树
```

## 关键概念一句话定位
| 概念 | 一句话 | 学习阶段 |
|------|--------|----------|
| 机器学习 | 喂数据让它学规律（房价预测） | 2 |
| 深度学习 | ML 一种，多层网络，擅长图/音/字 | 3 |
| NLP | 处理文字，理解与生成语言 | 4 |
| 大模型 LLM | 超大 DL 模型，训练海量文本，能对话写作 | 5 |
| AI Agent | 大模型当大脑 + 自己调工具/规划/记忆 | 6 |

## 核心洞察
- AI Agent 的"大脑"就是大模型(LLM)，所以阶段 3、5 是理解 Agent 的必经之路
- 但不用学完全部，阶段 5 之后就可以开始动手做 Agent
