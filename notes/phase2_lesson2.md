## 0. 昨天的 accuracy 掩盖了什么

accuracy（正确率）把两种完全不同的错误**混为一谈**：把生还者判死（漏报）和把遇难者判活（误报）。
极端例子：一个无脑模型把 891 人**全部判遇难**，正确率也有 **61.7%**（因为死亡率高）——分数不低，却一个生还者都没找到。
**你的模型必须和这个"基线"比，赢了才有意义。**

## 1. 混淆矩阵：把对错拆成四格

```
                     实际生还        实际遇难
预测生还            TP（真阳）      FP（误报）
预测遇难            FN（漏报）      TN（真阴）
```

以"生还 = 正类"：**TP** 预报生还且真生还；**FP** 误报（预报生还其实遇难）；**FN** 漏报（预报遇难其实生还）；**TN** 正确判死。

## 2. 精确率 / 召回率 / F1

| 指标 | 公式 | 语义（Titanic） |
|------|------|----------------|
| **精确率 precision** | TP/(TP+FP) | **预报可信度**：你预报的生还者里，多少是真的 |
| **召回率 recall** | TP/(TP+FN) | **覆盖率**：真生还者里，被你抓到了多少 |
| **F1** | 两者的调和平均 | 想两头兼顾时的单一分数 |

**优化谁看场景**：救生艇指挥官最怕**漏掉活人** → 看召回率；给"生还"发赔偿金、误报要赔钱 → 看精确率。

```python
from sklearn.metrics import confusion_matrix, precision_score, recall_score
confusion_matrix(y_test, pred)
precision_score(y_test, pred)   # 默认看"正类=1"=生还
recall_score(y_test, pred)
```

## 3. 治过拟合第一刀：max_depth

昨天你应该观察到：默认决策树 **train 分数 ≈ 1.0**（背题背满分），test 明显更低——这就是过拟合。

**第一刀：限制树深。** `DecisionTreeClassifier(max_depth=3)` 强迫树只问 3 层问题，背不了细节：
- train 分数**降**（不让背了）
- test 分数**升**（泛化变好）
- 差距缩小 = 更健康

把 depth 从 1 扫到 10，test 分数呈**倒 U**：太浅=欠拟合（学不动），太深=过拟合（背题），中间有最优值。

> 术语：`max_depth` 这种**训练前人为定的旋钮**叫**超参数（hyperparameter）**，调它们是阶段 2 的日常。
