# 核心口诀卡

> 用法：每次验收后我会把本课新口诀追加进来。复习时**先默写再对照**——这张卡是校对工具，不是背诵时偷看的答案。

## 索引与切片（9-29）
- `arr[i]` = 第 **i+1** 行（索引从 0 起）
- `[start:end]` **含头不含尾**，元素个数 = end − start

## numpy 运算（9-29）
- `*` 普通乘法（对位相乘）；`@` 矩阵乘法（点积求和）——普通的归 `*`，专业的归 `@`
- 广播：尾部维度匹配即可运算，短数组自动扩展；`(2,3)+(3,)` → `(2,3)`

## pandas 判别（10-01）
- **一层括号出列（Series），两层括号出表（DataFrame）**
- Series 身份证：结尾 `Name: xxx, dtype: xxx`
- `describe()` 只统计数值列；mean 和 50% 差距大 → 警觉极端值

## 清洗（10-01）
- 缺失用 dropna/fillna，重复用 drop_duplicates——**各管各的，dropna 不删重复**
- 清洗顺序影响结果：**先去重再填充**，均值不被重复值污染
- 重复值高于原均值则拉高、低于则拉低
- **`.0` 结尾 = 这列曾经混入过 NaN**（int 升 float64 不可逆，事后删/填都不变回去）
- 链式赋值不生效：`df[cond]['col']=x` 改的是临时副本；正确：`df.loc[cond,'col']=x` 或整列 fillna

## 统计（10-01）
- **mean 怕极端值，median 不怕**；有偏分布/含极端值用 median
- 分类列（字母）填充用众数 `mode()[0]`；mode 返回排序后的 Series
- 数每组几行用 `size()`（`.sum()` 是对数值列求和）

## 可视化（10-01）
- **比较几个类别 → bar**（x 轴是标签）；**看一列连续数据的分布 → hist**（x 轴是分桶）
- **groupby 必须接聚合**（mean/size…）；裸 groupby 只是"配方对象"，print 出内存地址

## 机器学习（10-02，持续更新中）
- 监督学习 = 特征 X → 标签 y；答案**带标签是分类**（会不会生还），**是数字是回归**（小费多少）
- 六步骨架：读数据 → X/y（清洗+编码）→ train_test_split → fit → predict → score
- **考试不能用原题**：test set 全程只碰一次；`random_state` 固定切分结果
- **X 里不能有 y 的影子**：漏删标签列 = 数据泄漏；score≈1.0 第一反应查泄漏，不是庆祝（铁证：importance 某列=1.0 其余全 0）
- drop(columns=...) **删列不删行**，行数不变
- train_test_split 一次返回 4 个值，四个变量接住；test 179 行 = 891×0.2 向上取整

## 评估指标（10-10）
- 混淆矩阵：**行=实际、列=预测**；TN 判死✓ / FP 判活✗ / FN 判死✗ / TP 判活✓
- 对角线 ÷ 总数 = accuracy——混淆矩阵就是"把 accuracy 拆成四格"
- **precision = 判活名单的可信度**（TP/(TP+FP)）；**recall = 救回率**（TP/(TP+FN)）
- precision=recall 只是这次 FP=FN 的**巧合**，不是规律
- 基线：全判多数类 `(y_test==0).mean()`——赢不过基线的模型等于没学
- `.score()`：**分类器 = accuracy，回归器 = R²**

## 过拟合（10-10）
- 方向口诀：**train↓ + test↑ = 泛化变好；train↑ + test↓ = 过拟合加深**
- `max_depth` 治过拟合第一刀：默认树 train 97.9/test 75.4（差 22.5）→ d=3 时 83.4/79.9（差 3.5）
- 测试集只 179 人 → 1 人 = 0.56%，曲线坑坑洼洼是样本太小，别过度解读

## 交叉验证（10-20）
- `cross_val_score(model, X_train, y_train, cv=5)` → **5 个分数**；`mean`=水平、`std`=稳定性
- **恒等式：考 1 次 + 学 (N−1) 次 = N 轮**（5 折 = 考 1 学 4）
  - 自证算法：5 折 × 712 人，若"各考 5 次"则考卷总人次 = 3560；实际只有 **712** 人次
- **铁律：CV 只在训练集上做**，那 179 人的测试集全程坐观众席
- CV 不是"分数更高"，是"分数可信可比较"（实测：单次切分极差 8.4pp，CV 只有 2.5pp）
- 同一份数据，CV 冠军（d=3）和单次切分冠军（d=5）**可以不一样**
- ⚠️ **CV 的折切分默认不洗牌**（`StratifiedKFold(shuffle=False)`）→ 完全确定，**不需要种子**，换运行环境也一样

## random_state 的两个位置（10-20 新增，易混）
- 位置① `train_test_split(..., random_state=)` = **改考卷的人**（谁当教材、谁当考卷）→ 换它分数抖 8.4pp
- 位置② `模型(random_state=)` = **改答题的人**（模型内部随机）→ 限深树抖 0，满树约 1.7pp，森林大量用
- ❌ 常见误解：以为 CV 也要种子。CV 默认不洗牌，是确定的，**不属于这两个位置**
- 单树不稳的真正原因：一路贪心分裂到底，噪声样本一挪，整棵树结构就变，**没有第二棵树稀释**

## 输出格式（10-20 起强制）
- `f-string`：`print(f"depth={d} mean={m:.4f} std={s:.4f}")`；`:.4f` = 保留 4 位小数
- 引号里的 `d` 是纯文本，不会被替换——字符与变量交替**必须**用 f-string

## 随机森林 / Bagging（10-29）

### 一句话总纲
**Bagging 只治方差，不治偏差。** 方差大才有得赚，方差小去套它反而亏。

### 两个旋钮（Breiman）
- **strength 强**（越高越好）= 单棵树有多准
- **ρ 相关**（越低越好）= 树与树错得有多像
- 方差下限 = **ρσ² + (1−ρ)σ²/B**（实测 ρ=0.596、ρσ²=0.1441，投票实测方差 0.1451，吻合）
- 反直觉：限深会把 ρ 从 0.596 抬到 0.688（更相关了），但 strength 涨得更多 → 净赚。**别以为集成只靠"去相关"**

### 三条硬事实
- **bootstrap 每棵树只看到 63.2% 的样本**（1−1/e）；两棵树的样本重叠 ≈ 40.0%
- 森林在 Titanic 上：单棵树单挑平均 **0.7672**（最差 0.6872），投票后 **0.7989**，**+3.2pp 全是"错得不一样"的收益**
- **森林 train 分数 = 满树 train 分数**（都是 0.9789）——它没有减少背题，只是让人一起投票

### 什么时候森林赢 / 输（Titanic 实测）
| 单树深度 | 单树 CV(5×10) | 森林 CV(5×10) | 增益 |
|---|---|---|---|
| None（满树） | 0.7656 | 0.8017 | **+3.61pp** |
| 8 | 0.8007 | 0.8267 | +2.60pp |
| 5 | 0.8096 | 0.8260 | +1.64pp |
| 3 | **0.8277** | 0.8063 | **−2.14pp** |

→ **判断顺序：先问"单树方差大不大"，再谈要不要集成。** d=3 单树 20 个种子极差 **0.0000**，没有方差可削，只剩 63.2% 抽样的损失。

### 默认参数（`RandomForestClassifier()`）
- `n_estimators=100`、`bootstrap=True`、`max_depth=None`（满树）、`max_features='sqrt'`
- 6 个特征 → `sqrt(6)≈2`，**每次分叉只看 2 个特征**——这就是第二个随机
- 两个随机 = **数据随机（bootstrap）+ 特征随机（max_features）**；`random_state` 只决定怎么抽，不是随机本身

### 别搞混的三个输出
| 输出 | 怎么合 |
|---|---|
| `predict`（标签） | **投票**（多数票） |
| `predict_proba`（概率） | **平均**（概率求均值） |
| `feature_importances_` | **平均**（100 棵树 importance 的算术平均，**没有"选第一"这一步**） |

### 森林 vs 单树 importance（Titanic）
- 森林：Fare .305 / Sex .271 / Age .260 / Pclass .078（**三分天下**）
- d=3 树：Sex .606 / Pclass .210 / Age .075 / Fare .061（**一枝独大**）
- 平均把偏见摊平；Fare 从小配角升到第一。但 Fare 与 Pclass 高度相关 → **importance 说"模型用了谁"，不说"谁在真实世界重要"**

### n_estimators 收敛
n=1 .7682 / 10 .8024 / 50 .8038 / 100 .8024 / 500 .8010（±0.0027 起就稳了）→ **50 棵之后基本无收益**

### OOB
`oob_score=True` 用没被抽到的 36.8% 当免费验证集：满树 0.8090（比 test .7989 乐观 1pp）、d=5 **0.8427 vs test .7933**（乐观 5pp）→ **限深时 OOB 会高估**，别全信
